# ESSE WORKSHOP

Интерактивная образовательная платформа по написанию эссе на казахском языке.

## Публикация
Сайт размещается через GitHub Pages из ветки `main`. Основная страница — `index.html`.

## Firebase: отзывы и панель администратора

1. В Firebase Authentication включён провайдер Email/Password.
2. В Authentication → Users создан отдельный аккаунт администратора.
3. В `firebase-config.js` значение `adminEmail` должно совпадать с email этого аккаунта.
4. В Firestore Database → Rules опубликовано содержимое `firestore.rules`.
5. В Authentication → Settings → Authorized domains добавлен домен `35schoolkz.github.io`.

В интерфейсе сайта администратор вводит короткий логин, который преобразуется в email из конфигурации, и пароль Firebase Authentication. Пароль в исходном коде сайта не хранится.

## Правила доступа

- Посетители могут только создавать отзывы с проверяемыми полями.
- Читать, изменять и удалять отзывы может только аккаунт администратора.
- Все остальные документы Firestore закрыты правилами.
- Firebase Web API key в `firebase-config.js` — публичная часть клиентской конфигурации, а не пароль или приватный ключ.
- Никогда не добавляйте в репозиторий пароли, service-account JSON или приватные ключи.

## Важные ограничения и усиление защиты

- Сейчас учебный прогресс хранится локально в браузере и не синхронизируется между устройствами.
- Для публичного запуска включите Firebase App Check (reCAPTCHA Enterprise для веб-приложения) и настройте его в Firebase Console. Это помогает снизить автоматический спам, но не заменяет Firestore Rules.
- Используйте длинный уникальный пароль администратора. Простой пароль вроде `admin1` подходит только для временной демонстрации и небезопасен для реального использования.
- Следите за квотами Firebase и включите уведомления о расходах/лимитах, если они доступны в вашем плане.

## Разработка

Основные файлы:
- `index.html` — интерфейс, уроки, тест, конструктор эссе и отзывы.
- `firebase-config.js` — публичная конфигурация Firebase и email администратора.
- `firestore.rules` — серверные правила доступа к Firestore.
