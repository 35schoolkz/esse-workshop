# Эссе шеберханасы

Интерактивная образовательная платформа на казахском языке: пять уроков по структуре эссе, тест из 15 вопросов, конструктор эссе, словарь, образец текста и локальное сохранение прогресса.

## Публикация
GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Главная страница: `index.html`.
